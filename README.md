# ACG 卡牌构筑器

一个基于 GitHub Pages、Supabase 和 Tabletop Simulator（TTS）的 ACG 卡牌收藏、构筑与导入工具。

**网页地址：** https://ren-scarlet.github.io/ACG-/

## 玩家首次使用

1. 打开网页，在「玩家账号」注册账号，使用邮箱和密码登录。
2. 等待管理员把你的账号绑定到原有玩家编号（例如 P001）。
3. 进入「卡组构筑」，点击「读取我的收藏并开始构筑」。
4. 构筑完成后生成分享链接，再把链接粘贴到 TTS 的 ACG 导入器。
5. 每位玩家都可以独立导入自己的卡组，不需要房主在线。

玩家编号用于保留旧收藏和玩家中心记录；真正的账号身份由 Supabase Auth 登录会话确认。不要把账号密码交给管理员。

## 卡组与库存

- 卡组草稿和本地保存的卡组保存在玩家自己的浏览器中，不会自动同步到其他设备。
- 分享链接包含卡牌 ID 与数量，收到链接的人可以查看卡组。
- 正式收藏库存保存在 Supabase，由登录账号隔离。
- 普通卡牌构筑不会扣除库存。
- 类型为「对战道具」的卡牌会在确认生成分享链接时从库存永久扣除；此功能须在部署数据库迁移并发布对战道具卡牌后才可使用。
- 旧版 `data/collections.json` 只作为迁移快照。迁移完成并核对成功后，应从公开站点移除旧库存数据。

## TTS 导入

导入器模块：[`tts/ACG_Importer.lua`](tts/ACG_Importer.lua)

使用说明：[`docs/tts-importer.md`](docs/tts-importer.md)

每位玩家分别粘贴自己的卡组分享链接并点击导入。已实测不同玩家可分别导入不同卡组，卡牌进入对应玩家手牌区。

## 管理员

管理员在玩家中心可绑定玩家编号、调整玩家收藏、登记和更正比赛、发放代币、管理成就与设置抽卡卡池。

卡牌、卡包和卡图仍由 GitHub 仓库管理。管理员写入仓库时需要 GitHub Contents 写权限的访问令牌；令牌只保留在当前页面内存中，不要粘贴到聊天、公开页面或仓库文件。

## 今晚上线部署

1. 先执行 [只读数据库预检](supabase/launch-preflight.sql)，把结果交给项目维护者确认现有 Supabase 表、RLS、管理员函数和注册触发器。
2. 预检确认通过后，再执行 [统一上线迁移](supabase/tonight-launch.sql)。
3. 按 [今晚部署步骤](docs/tonight-launch.md) 绑定玩家账号、核对旧收藏并进行 TTS 验收。

不要在预检未通过时直接执行迁移，也不要在确认旧收藏迁移成功前删除旧收藏快照。
