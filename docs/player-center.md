# 玩家中心（开发中）

玩家中心在原有卡牌图鉴、收藏管理、卡组构筑和 TTS 导入器之外独立增加，不替换旧的玩家编号体系。

## 当前这一阶段包含

- 公开主页：按游戏昵称查询公开资料；只显示昵称、加入时间、称号、徽章和比赛统计。
- 玩家个人中心：查看自己的比赛记录、代币流水、成就和 Supabase 收藏数据。
- 管理员比赛管理：登记 2v2 比赛、更正最近比赛、删除错误比赛；数据库会从比赛记录重算四名玩家的场次、胜场和败场。
- 管理员发币：通过数据库 RPC 同时更新余额和代币流水。
- 成就：预置 12 项基础成就；比赛、收藏和抽卡记录变化时自动检查；已解锁成就不会因后续数据变化而删除。

## 部署步骤

1. 先检查本分支的数据库迁移文件：`supabase/migrations/001_player_center_core.sql`。
2. 确认后合并本分支，再将该 SQL 文件完整复制到 Supabase SQL Editor 执行。
3. 用户注册成功后，管理员账号可由受信管理员在 SQL Editor 中设置：
   ```sql
   update public.profiles
   set is_admin = true
   where lower(username) = lower('RenScarlet')
   returning username, is_admin;
   ```
4. 刷新网页并登录管理员账号，打开「玩家中心」即可使用比赛登记与代币发放。

## 重要安全说明

- 不要把 Supabase service_role/secret key 放入网页。
- 玩家不能直接修改余额、比赛结果、收藏、成就或管理员身份。
- 比赛登记、更正、删除和代币发放只允许通过管理员 RPC。
- 公开主页通过单独的 `public_profiles` 视图读取，不向访客开放 profiles 原表。
- 此阶段的代币成就奖励默认值为 0；抽卡价格和卡池规则确定后再配置，避免提前写入错误经济数值。
