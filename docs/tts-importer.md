# ACG 卡牌构筑器 × Tabletop Simulator（TTS）导入器

本目录提供一个嵌入现有 TTS Global 脚本的 Lua 模块。它读取网页生成的卡组分享链接，再从 GitHub Pages 获取当前卡牌资料，并在 TTS 桌面上生成对应的自定义卡牌。

**网页地址：** https://ren-scarlet.github.io/ACG-/

## 一、整合前备份

1. 在 TTS 中保存当前存档。
2. 建议另存一份备份，以便出现问题时恢复。
3. 打开当前存档使用的 Global Lua 脚本。

## 二、将模块整合进现有 Global

这是供现有 Global 使用的模块，**不是完整 Global 脚本**。它不定义 `onLoad()`，也不会自行调用 `UI.setXml()`，以免覆盖原有界面。

1. 在现有 Global 脚本中找到 `applyAllUI()`。
2. 找到原本负责设置 UI 的这一行：

   ```lua
   UI.setXml(CBOX_UI_XML .. "\n" .. baseXmlNow() .. "\n" .. (FOOD_MENU_UI_XML or ""))
   ```

3. 将这一行替换为：

   ```lua
   UI.setXml(CBOX_UI_XML .. "\n" .. baseXmlNow() .. "\n" .. (FOOD_MENU_UI_XML or "") .. "\n" .. (ACG_UI_XML or ""))
   ```

4. 保留原有 `applyAllUI()` 中后面的 `restoreQueryUI()` 等原有逻辑，不要删除。
5. 将仓库中的 `tts/ACG_Importer.lua` 模块代码完整复制，粘贴到现有 Global 脚本末尾。
6. 保存脚本并运行存档（Save & Play）。

如果你的 Global 脚本结构与上述示例不同，不要盲目替换其他代码；应先确认 UI 汇总位置，避免覆盖原有系统。

## 三、导入卡组

1. 在网页构筑器中构筑卡组并生成分享链接。
2. 在 TTS 左下方点击「ACG 卡组导入」。
3. 将完整分享链接粘贴到输入框。
4. 点击「读取链接并生成卡牌」。
5. 等待状态提示显示导入完成。

分享链接采用网页当前的 `#deck=` 格式，数据版本为 `version: 1`。链接中保存卡牌稳定 ID 与数量；导入器会读取当前公开的 `data/cards.json`，因此旧链接也会使用当前卡牌资料中的名称、图片和效果。

## 四、当前导入行为

- 每张卡牌按分享链接中的数量逐张生成 TTS 自定义卡。
- 卡牌生成在桌面中央附近，按网格排列。
- 当前没有自动将卡牌分配到四名玩家的座位区域；玩家可在 TTS 中自行整理。
- 当前暂用卡牌正面图片作为卡背。
- 导入器只生成卡牌，不修改网页收藏数据，也不会扣除或替换玩家收藏盒中的卡牌。
- 再次导入会再次生成一批卡牌；导入器不会自动清理之前生成的卡牌。

## 五、常见错误提示

- **没有找到 `#deck=` 分享数据：** 请从网页复制完整分享链接，不要只复制卡组名称或卡组内容。
- **读取卡牌资料失败：** 检查 TTS 网络连接，以及网页是否可以正常打开。
- **找不到卡牌 ID：** 分享链接引用的卡牌 ID 已不在当前公开卡牌资料中，或卡牌资料尚未发布。
- **卡牌资料 JSON 无法解析：** 检查仓库中的 `data/cards.json` 是否为有效 JSON。
- **有卡牌生成失败：** 查看 TTS 控制台中的 `[ACG]` 信息，并检查图片链接及 TTS 网络访问情况。

## 六、相关文件

- `tts/ACG_Importer.lua`：导入器模块。
- `data/cards.json`：导入器读取的公开卡牌资料。
- 网页分享链接：提供卡牌 ID 与数量。
