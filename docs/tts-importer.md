# ACG 卡牌构筑器 × TTS 导入器（Global 整合版）

## 重要：这是嵌入现有 Global 的模块，不是完整 Global 脚本

如果你的 Global 已经有其他系统和 onLoad()，不要把本文件当作整份 Global 脚本覆盖粘贴。本模块不定义 onLoad()，也不单独调用 UI.setXml()，避免覆盖现有系统。

## 整合步骤

1. 先在 TTS 中保存当前存档，最好另存一份备份。
2. 打开现有 Global Lua 脚本。
3. 找到现有的 applyAllUI()，其中原本有这一行：

   UI.setXml(CBOX_UI_XML .. "\\n" .. baseXmlNow() .. "\\n" .. (FOOD_MENU_UI_XML or ""))

4. 只把这一行替换为：

   UI.setXml(CBOX_UI_XML .. "\\n" .. baseXmlNow() .. "\\n" .. (FOOD_MENU_UI_XML or "") .. "\\n" .. (ACG_UI_XML or ""))

5. 保留原有 applyAllUI() 中后面的 restoreQueryUI()，不要删除。
6. 将本文件的 Lua 模块代码完整复制，粘贴到现有 Global 脚本最末尾，也就是原有“附录结束”注释的后面。
7. 点击 Save & Play。

## 使用方式

1. 游戏重新载入后，屏幕左下方会出现「ACG 卡组导入」按钮。
2. 点击按钮打开导入面板。
3. 粘贴网页生成的完整卡组分享链接。
4. 点击「读取链接并生成卡牌」。
5. 等待状态提示显示导入完成。

## 现阶段限制

- 目前按卡牌数量逐张生成 TTS 自定义卡，还没有合并成 Custom Deck。
- 卡牌会生成在桌面中央附近，暂未按四名玩家的座位分区。
- 暂时使用卡牌正面作为背面。
- 尚未在你的实际 TTS 存档中完成联调，第一次运行后需要根据客户端表现继续修正。
- 本模块只负责导入，不修改收藏数据，也不删除或替换卡片收藏盒。

## 分享数据兼容

继续使用网页现有的 version: 1 和稳定卡牌 ID。旧分享链接仍按卡牌 ID 读取最新的卡名、卡图和效果。
