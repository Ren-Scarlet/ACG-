# ACG 卡牌构筑器 × TTS 导入器（第一版）

## 当前网页分享协议

网页当前生成的分享链接格式：

- URL：网页地址 + `#deck=` + Base64URL 编码数据
- 数据版本：`version: 1`
- 数据结构：

```json
{
  "version": 1,
  "cards": [
    { "id": "card_001", "quantity": 2 },
    { "id": "card_002", "quantity": 1 }
  ],
  "valid": true
}
```

TTS 导入器只依赖稳定的卡牌 ID 和数量；卡图、名称、效果等资料从公共的 `data/cards.json` 读取。这样以后修改卡图或效果，不必改变旧卡组链接。

## 安装方式（测试版）

1. 在 TTS 打开你的存档。
2. 点击顶部的 **Scripting（脚本）**。
3. 打开 **Global** 脚本。
4. 将 `ACG_Importer.lua` 的完整内容粘贴进去。
5. 点击 **Save & Play**。
6. 在桌面出现的 ACG 导入面板中粘贴网页卡组分享链接。
7. 点击「读取链接并生成卡牌」。

## 第一版的范围

- 从分享链接解析 `#deck=` 数据。
- 从 GitHub Pages 下载最新的 `cards.json`。
- 通过卡牌 ID 匹配卡牌资料。
- 按数量逐张生成 TTS 自定义卡牌。
- 卡牌名称和效果写入 TTS 对象信息。

## 当前测试限制

- 目前使用单张自定义卡生成，不合并成 TTS Custom Deck。
- 暂时在桌面中央生成，尚未按四名玩家的座位自动分区。
- 尚未加入重复导入检测、批量清理和卡组区域管理。
- 暂时用卡牌正面图片作为背面。之后加入统一卡背图片后，只需设置脚本顶部的 `ACG_CARD_BACK_URL`。
- 这是第一版联调脚本，尚未在用户的 TTS 客户端实际运行验证。

## 稳定性约定

- 卡牌 ID 永久固定，例如 `card_001`。
- 图片路径可修改，但必须保证 `cards.json` 中的 `image` 指向公开可访问的图片。
- 不要将卡牌名称作为匹配键；名称可能修改，ID 不应修改。
- 分享数据版本升级时保留旧版本解析能力，避免旧链接失效。
