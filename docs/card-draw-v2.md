# 抽卡系统 v2 迁移说明

## 本次规则

- 每包 5 张卡；单抽购买 1 包，十连购买 10 包（共 50 张）。
- 每张卡独立判定稀有度，概率最多支持两位小数。
- 概率从高到低：异画、五星（SSR）、四星（SR）、三星（R），合计必须为 100%。
- 无异画卡的卡包，异画概率填 0%；有异画卡的卡包可设置 0.1%。
- 分解返还：三星 10、四星 15、五星 20、异画 30 代币/张。

## 部署步骤

1. 在 Supabase Dashboard 打开 SQL Editor。
2. 将本目录的 `supabase/card-draw-v2.sql` 全文粘贴并执行一次。
3. 确认 SQL Editor 没有报错。
4. 迁移会暂时暂停现有卡池，避免旧概率继续抽取。
5. 等待 GitHub Pages 更新后，强制刷新网站（Ctrl+F5）。
6. 管理员进入「玩家中心」→「管理员 · 玩家管理」→「卡池设置」，逐个选择卡包，设置每包价格和概率后保存。保存后该卡包才会重新开放。

## 概率填写建议

有异画卡的卡包：
- 异画 0.10%
- 五星 1.20%
- 四星 5.00%
- 三星 93.70%

没有异画卡的卡包：
- 异画 0.00%
- 五星 1.20%
- 四星 5.00%
- 三星 93.80%

当前四个卡包：
- pack_001 无限泡影：无异画卡，异画概率必须填 0。
- pack_002 梦幻：有异画卡。
- pack_003 固拉多：有异画卡。
- pack_004 盖欧卡：有异画卡。

## 安全与数据

迁移会保留玩家现有代币、卡牌库存和历史记录；更新抽卡目录为仓库当前 47 张卡牌。新抽卡与分解都由数据库事务执行，并使用请求编号防止网络重试造成重复扣款或重复发币。

旧版单张抽卡 RPC 会被撤销执行权限，避免绕过每包 5 张的新规则。

注意：代码已推送到 GitHub，但必须先在 Supabase 执行迁移，再设置各卡包价格和概率，抽卡新流程才会正式可用。
