# 首页背景音乐

将你拥有使用权的背景音乐文件放在本目录，并命名为：

`main-theme.mp3`

网站首页右下角的播放器会读取：

`./assets/bgm/main-theme.mp3`

## 替换音乐
1. 准备 MP3 音频文件。
2. 用新音乐覆盖 `main-theme.mp3`，文件名保持不变。
3. 提交到 GitHub，等待 GitHub Pages 部署完成。
4. 刷新网站即可使用新音乐。

播放器支持播放/暂停、音量调节和循环播放。不会未经用户操作自动播放；用户主动开启过音乐后，浏览器允许时会尝试恢复播放。

当前仓库不包含音乐音频本身。把你的音乐文件放到这里即可，无需修改网页代码。
